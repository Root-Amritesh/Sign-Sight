## How to run the code

*Make sure you have nodejs with npm as well as python installed. Latest version works fine

## Installation guide

### Frontend
1) Unzip the folder and navigate to frontend directory
   ```cd Sign-Sight/frontend```
2) Run
   ``` npm install ```
   ``` npm run dev ```
3) You can also do the build version using ```npm run build``` and then running the final build generated in DIST but the project is not completed yet.
